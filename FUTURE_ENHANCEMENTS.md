## Keep Hosting Free

Prefer browser-side features and static hosting on GitHub Pages. Use Hugging Face free-tier APIs or Spaces only within current free limits, with clear quota/error states. Avoid requiring paid model access, paid hosting, or a billing-enabled fallback. Review provider terms and quotas before adding integrations.
